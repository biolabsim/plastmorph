# PlastMorph

PlastMorph helps high school students explore how plastics degrade under different environmental conditions.

## Learning Goals

- Compare how material chemistry affects degradation speed.
- Understand how environmental factors influence decomposition.
- Build intuition for why plastics persist in some ecosystems.

## App Workflow

1. Select a plastic material and base environment.
2. Modify variables to create a custom scenario.
3. Simulate over time and inspect mass decay and shape evolution.
